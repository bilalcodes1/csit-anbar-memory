# ذاكرة الكلية

واجهة أولية لأرشيف دفعات **كلية علوم الحاسوب وتكنولوجيا المعلومات – جامعة الأنبار**.

المشروع مصمم كتجربة عربية RTL تجمع بين **Yearbook رقمي** و**Photo Map** تحفظ صور الدفعات، السنوات، الأسماء، واللحظات التي تصنع ذاكرة الكلية. النسخة الحالية تتضمن:

- واجهة افتتاحية فاخرة ودافئة.
- خطًا زمنيًا للدفعات.
- خريطة ذكريات تفاعلية تربط النقاط بالسنوات والدفعات.
- بطاقات قابلة للتصفية حسب الحالة.
- نافذة تفاصيل لكل دفعة.
- تصميمًا متجاوبًا مع الهاتف.

## اتجاه المنتج

كل دفعة مستقبلًا تحصل على صفحة Yearbook خاصة بها تشمل:

- غلاف وصورة جماعية.
- سنة القبول والتخرج والتخصص.
- أسماء الطلبة.
- معرض الصور والأنشطة.
- أحداث وذكريات مرتبطة بالدفعة.

وتتحول خريطة الذكريات تدريجيًا إلى واجهة تربط الصور بالسنوات والأماكن داخل الكلية، بدل عرض الصور كشبكة منفصلة فقط.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح `http://127.0.0.1:8000`.

## البنية المقترحة للبيانات

```text
assets/
└── batches/
    ├── 2022/
    │   ├── group.webp
    │   └── gallery/
    ├── 2023/
    └── 2024/
```

الصور والأسماء الحقيقية للدفعات تضاف بعد اعتماد المحتوى وموافقات النشر. صور البطاقات الحالية صور أرشيفية للمعاينة البصرية وليست صور دفعات نهائية.
