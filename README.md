# ذاكرة الكلية

أرشيف رقمي قابل للتوسع لدفعات **كلية علوم الحاسوب وتكنولوجيا المعلومات – جامعة الأنبار**.

المشروع مصمم كواجهة عربية RTL مع بنية Cloudflare قابلة للإدارة تحفظ صور الدفعات، السنوات، الأسماء، واللحظات التي تصنع ذاكرة الكلية. النسخة الحالية تتضمن:

- واجهة افتتاحية فاخرة ودافئة.
- خطًا زمنيًا للدفعات.
- بطاقات قابلة للتصفية حسب الحالة.
- نافذة تفاصيل لكل دفعة.
- تصميمًا متجاوبًا مع الهاتف.
- أيقونة هوية أصلية مستوحاة من فكرة تطبيقات الصور، لتوضيح وظيفة الأرشيف بصريًا.
- واجهة إدارة عربية لإضافة دفعة بعد تفعيل Cloudflare.
- Cloudflare Pages Functions للـAPI.
- Cloudflare D1 للدفعات والألبومات والأسماء.
- Cloudflare R2 لتخزين الصور.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح `http://127.0.0.1:8000`.

## تشغيل Cloudflare

1. أنشئ مشروع Pages باسم `csit-anbar-memory`.
2. أنشئ قاعدة D1 باسم `csit-anbar-memory` واربط معرّفها في `wrangler.toml`.
3. أنشئ حاوية R2 باسم `csit-anbar-memory-images`.
4. طبّق الترحيل:

```bash
npx wrangler d1 migrations apply csit-anbar-memory --remote
```

5. أضف المتغير السري `ADMIN_TOKEN` في إعدادات Pages Functions، ولا تضعه داخل الملفات.
6. اربط D1 بالاسم `DB` وR2 بالاسم `IMAGES`.
7. افتح `/admin.html` لإضافة الدفعات بعد تسجيل الدخول بالرمز السري.

الـAPI العام:

- `GET /api/batches` يعرض الدفعات المنشورة.
- `GET /api/batches/:year` يعرض تفاصيل دفعة وألبوماتها.
- `GET /media/:key` يعرض الصور من R2.

الـAPI الإداري:

- `POST /api/admin/batches` لإضافة دفعة.
- `POST /api/admin/upload` لرفع صورة.

لا يُعتبر المشروع جاهزًا للنشر العام قبل إضافة الصور الرسمية، اعتماد الأسماء، وضع سياسة تواصل للحذف والتصحيح، وربط معرّف قاعدة D1 الحقيقي.

## البنية المقترحة للبيانات

```text
assets/
└── batches/
    ├── 2022/
    │   ├── group.webp
    │   └── gallery/
    ├── 2023/
    └── 2024/
```

الصور والأسماء الحقيقية للدفعات تضاف بعد اعتماد المحتوى وموافقات النشر. صور البطاقات الحالية صور أرشيفية للمعاينة البصرية وليست صور دفعات نهائية.
